# 如果世界听你的 · Your Imagination, Our World

Phase 0 prototype: one real-time 3D world (React Three Fiber) rendered in three candidate art directions.

```
npm install
npm run dev      # http://localhost:5173/?style=a   (a = 晨光电影感, b = 绘本手绘风, c = 微缩模型)
npm run build
```

Drag the sun on the bottom dial to change the time of day (real sun direction, sky, fog, light colour and shadows).
Orbit / zoom / pan with mouse or touch. See `docs/PHASE0.md` for structure, tooling and screenshot scripts.
